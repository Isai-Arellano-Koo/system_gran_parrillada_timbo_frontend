# Frontend — Gran Parrillada Timbó

React + TypeScript + Vite. Consume la API del backend según roles (admin, mesero, cocinero).

## Arranque

1. Copia `.env.example` a `.env` (ya existe `.env` con `VITE_API_URL`).
2. `npm install`
3. `npm run dev` → http://localhost:5173

## Variables

| Variable | Descripción |
|----------|-------------|
| `VITE_API_URL` | Base URL del backend (ej. `http://localhost:3000`) |

## Pantallas

- Login (HU01)
- Ingredientes / Platos-recetas / Inventario (admin)
- Pedidos (mesero/admin)
- Cocina (cocinero/admin/mesero consulta)
